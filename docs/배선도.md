# 배선도

핀 번호는 모두 `braille_reader/config.py`에서 바꿀 수 있다. (GPIO = BCM 번호, 괄호 = 물리 핀 번호)

## ⚠ 먼저 확인할 것

1. **서보 전원은 라즈베리파이에서 끌어오지 않는다.** SG90 6개가 동시에 움직이면 순간 전류가 수 A까지 올라가 파이가 재부팅된다. 반드시 5V 5A 어댑터 → PCA9685의 `V+` 단자로 공급한다.
2. **GND는 모두 공통으로 묶는다.** 어댑터 GND, PCA9685 GND, 라즈베리파이 GND가 연결되어야 PWM 신호가 제대로 전달된다.
3. **GPIO는 3.3V 전용이다.** 버튼 모듈과 엔코더의 VCC를 3.3V에 연결하면 로직레벨 컨버터가 필요 없다. 모듈을 5V로 쓸 때만 컨버터를 거친다.

## PCA9685 (I2C)

| PCA9685 | 연결 |
|---|---|
| VCC | 3.3V (1) |
| GND | GND (6) |
| SDA | GPIO2 / SDA (3) |
| SCL | GPIO3 / SCL (5) |
| V+ (녹색 단자대 +) | 5V 5A 어댑터 + |
| GND (녹색 단자대 −) | 5V 5A 어댑터 − (그리고 파이 GND와 공통) |

| PCA9685 채널 | 서보 | 점자 점 |
|---|---|---|
| 0 | 서보 1 | 점 1 (왼쪽 위) |
| 1 | 서보 2 | 점 2 (왼쪽 가운데) |
| 2 | 서보 3 | 점 3 (왼쪽 아래) |
| 3 | 서보 4 | 점 4 (오른쪽 위) |
| 4 | 서보 5 | 점 5 (오른쪽 가운데) |
| 5 | 서보 6 | 점 6 (오른쪽 아래) |

SG90 선 색: 갈색 = GND, 빨강 = V+, 주황 = 신호(PWM)

## 4버튼 모듈

버튼은 내부 풀업을 사용하므로 눌렀을 때 GND와 연결되면 된다.

| 버튼 | 기능 | GPIO |
|---|---|---|
| K1 | 촬영 + OCR | GPIO17 (11) |
| K2 | 다음 셀 | GPIO27 (13) |
| K3 | 이전 셀 | GPIO22 (15) |
| K4 | 처음부터 | GPIO23 (16) |
| GND | — | GND (14) |
| VCC (있다면) | — | 3.3V (17) |

## KY-040 로터리 엔코더 (추가 기능)

| KY-040 | 연결 |
|---|---|
| CLK | GPIO5 (29) |
| DT | GPIO6 (31) |
| SW | GPIO13 (33) |
| + | 3.3V (17) |
| GND | GND (30) |

`config.py`에서 `ENCODER_ENABLED = True`로 바꿔야 동작한다.

## Camera Module 3

CSI 카메라 포트에 리본 케이블 연결 (파란 면이 이더넷 포트 쪽). Pi 4는 22핀→15핀 변환이 필요 없는 표준 15핀 케이블을 사용한다.
