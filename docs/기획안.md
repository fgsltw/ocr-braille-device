# 기획안 — OCR 기반 한글 인식 및 촉각 점자 출력 장치 (MVP)

## 0. 시작 전 세 가지 질문

| 질문 | 답 |
|---|---|
| **무엇을** 만드는가? | 인쇄된 한글 문서를 카메라로 찍으면 OCR로 읽고, 한글 점자로 바꿔 6핀(서보모터) 점자 셀로 한 칸씩 출력하는 장치 |
| **왜** 중요한가? | 시각장애인이 점역되지 않은 일반 인쇄물(안내문, 메모, 라벨 등)을 화면이나 타인의 도움 없이 손끝으로 직접 읽을 수 있게 한다 |
| **어디까지**가 완성인가? | 인쇄된 `가나다`를 촬영 → OCR → 점자 변환 → 서보 출력까지 수행하고, 버튼으로 이전·다음 셀을 오가며 끝까지 읽을 수 있으면 완성 |

### 범위

이 프로젝트는 웹 서비스가 아닌 **단독 실행 하드웨어 장치**다.

- 화면 없음 (사용자는 버튼 + 촉각으로만 조작)
- 서버 없음 (OCR까지 라즈베리파이 안에서 오프라인 처리)
- DB 없음 (인식한 문장은 메모리에만 보관)

## 1. 대상 사용자

- 점자를 읽을 수 있는 시각장애인
- 시연·평가자 (MVP 단계)

## 2. 핵심 기능 (Must Have)

1. **촬영 + OCR** — 버튼 1을 누르면 Camera Module 3로 촬영하고 RapidOCR(PP-OCRv5 한국어 모델, 기본값) 또는 Tesseract(kor)로 한글 문자열을 추출한다. 모두 라즈베리파이 안에서 오프라인으로 동작한다. 조명이 일정하고 인쇄 상태가 양호한 짧은 문장만 지원한다.
2. **한글 → 점자 변환** — 한글 음절을 초성·중성·종성으로 분해해 한국 점자 규정의 기본 자모 규칙으로 6점 셀 배열을 만든다.
   - 초성 `ㅇ`은 생략, 된소리는 된시옷(⠠) + 자음
   - 예: `가` → `[⠈, ⠣]` (약자 끔)
   - 약자·약어 규칙 적용 (기본 켬, `config.py`의 `BRAILLE_ABBREVIATIONS`): `가`→⠫, `한글`→⠚⠒⠈⠮, `그리고`→⠁⠥
3. **6서보 촉각 출력** — PCA9685로 SG90 6개를 제어해 셀 하나를 돌기 상승/하강으로 표현한다.
4. **버튼 탐색** — 4버튼: 촬영 / 다음 / 이전 / 처음부터.

## 3. 추가 기능 (Nice to Have — 이번 MVP에서는 기본 꺼짐 또는 미구현)

| 기능 | 상태 |
|---|---|
| 로터리 엔코더 탐색 | 코드 포함, `config.py`에서 `ENCODER_ENABLED = True`로 켬 |
| 약자 (가·나·다…하, 것, 억·언…인, 성·정·청) | **구현** (기본 켬, `--no-abbrev`로 끔) |
| 약어 (그래서·그러나 등 7개) | **구현** (약자와 같은 설정으로 켜고 끔) |
| 숫자·문장부호 | **구현** (. ? ! , · : / - ― ~ ( ) 따옴표 줄임표, 2024 규정 원문 대조). 영어 등 그 밖의 문자는 건너뜀 |
| 모음 연쇄 구분표(예: `아예`의 ⠤) | **구현** (항상 적용) |
| OCR 오류 수정, 여러 줄 문서 | 미구현 |
| 출력 속도 조절 | **구현** — 버튼 2 길게 누르기로 자동 읽기 켜기/끄기, 자동 읽기 중 버튼 2/3으로 빠르게/느리게 (5단계) |

## 4. 이번에 하지 않는 것

- 화면(LCD/웹 UI), 음성 출력(TTS)
- 서버·클라우드 OCR, 네트워크 기능, 로그인
- 여러 셀 동시 출력 (셀은 1개만)
- 손글씨 인식, 영어 점자, 수학·특수 기호(% 등)
- 표준 크기(점 간격 약 2.5mm) 점자 셀 기구 — MVP는 확대 셀(6mm) 3D 프린트 모델 사용 ([기구.md](기구.md), `hardware/`)

## 5. 시스템 동작 흐름

1. 버튼 1 → 촬영
2. OCR → 문자열
3. 점자 변환 → 셀 배열
4. 첫 셀 출력
5. 버튼 2/3(또는 엔코더)으로 다음/이전 셀
6. 마지막 셀 이후 버튼 4로 처음부터, 또는 버튼 1로 새 문서

| 부품 | 수량 | 역할 |
|---|---:|---|
| Raspberry Pi 4 | 1 | OCR 및 전체 제어 |

배선은 [배선도.md](배선도.md) 참고.

## 7. 성공 기준

| 항목 | 기준 |
|---|---|
| OCR | 일정한 조명에서 인쇄된 짧은 한글 문장 인식 |
| 점자 변환 | 지원 글자를 올바른 셀 배열로 변환 (자동 테스트로 확인) |
| 서보 | 6개 돌기 개별 상승·하강 |
| 촉각 | 손끝으로 패턴 구분 가능 |
| 조작 | 버튼으로 이전·다음 이동 정상 |
| 통합 | 촬영 → OCR → 변환 → 출력 전 과정 정상 |

## 8. 시연 시나리오 — "가나다"

1. 인쇄된 `가나다`를 카메라 앞에 둔다.
2. 버튼 1을 누른다.
3. OCR이 `가나다`를 인식한다.
4. 셀 배열 `⠫ ⠉ ⠊` (3셀, 약자 적용)로 변환한다. 약자를 끄면 `⠈ ⠣ ⠉ ⠣ ⠊ ⠣` (6셀).
5. 첫 셀 `⠫`(1-2-4-6점)을 출력한다.
6. 버튼 2로 다음 셀로 이동하며 마지막 셀까지 읽는다.
