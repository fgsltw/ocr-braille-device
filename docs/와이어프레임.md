# 와이어프레임 — 장치 외형 및 조작 흐름

이 장치에는 화면이 없다. 와이어프레임은 **손이 닿는 면(조작부)의 배치**와 **버튼에 따른 상태 변화**로 대신한다.

## 1. 장치 윗면 배치 (위에서 본 모습)

```
 ┌──────────────────────────────────────────────────────┐
 │   [ 카메라 거치대 ]  ← 문서를 아래에 두고 촬영           │
 │         ▼                                            │
 │   ┌──────────────── 문서 놓는 자리 ───────────────┐    │
 │   │                                              │    │
 │   └──────────────────────────────────────────────┘    │
 │                                                      │
 │   점자 셀 (돌기 6개)        버튼              엔코더    │
 │     ┌─────────┐                                       │
 │     │ (1) (4) │      [1 촬영]  [2 다음]       ( ◎ )    │
 │     │ (2) (5) │      [3 이전]  [4 처음]     돌림/누름   │
 │     │ (3) (6) │                                       │
 │     └─────────┘                                       │
 │    왼손 검지로 읽기       오른손으로 조작                   │
 └──────────────────────────────────────────────────────┘
```

- 돌기 번호는 표준 점자 번호(왼쪽 열 1-2-3, 오른쪽 열 4-5-6)와 같다.
- 버튼은 손으로 더듬어 구분할 수 있도록 2×2로 배치하고, 버튼 1(촬영)에 촉각 표시(돌기 스티커 등)를 붙인다.

## 2. 상태 흐름

```
            ┌──────────┐
  전원 ON → │  대기     │  모든 돌기 내림
            └────┬─────┘
                 │ 버튼1
                 ▼
            ┌──────────┐  인식 실패 / 글자 없음
            │ 촬영+OCR  │ ─────────────────────→ 오류 패턴 출력(돌기 6개 모두 올림 2회 깜빡임) → 대기
            └────┬─────┘
                 │ 성공
                 ▼
            ┌──────────┐  버튼2 / 엔코더 시계방향  → 다음 셀 (마지막이면 끝 신호)
            │ 읽기      │  버튼3 / 엔코더 반시계방향 → 이전 셀 (처음이면 끝 신호)
            │ (셀 i)   │  버튼4                   → 0번 셀
            │          │  엔코더 누름              → 현재 셀 다시 출력
            └────┬─────┘  버튼1                   → 새 문서 촬영
                 │ ▲
   버튼2 길게 누름 │ │ 버튼2 길게 누름 / 마지막 셀 도달(끝 신호) / 버튼1
                 ▼ │
            ┌──────────┐  (일정 간격마다 다음 셀로 자동 이동)
            │ 자동 읽기  │  버튼2 / 엔코더 시계방향  → 더 빠르게 (가장 빠르면 끝 신호)
            │          │  버튼3 / 엔코더 반시계방향 → 더 느리게 (가장 느리면 끝 신호)
            │          │  버튼4                   → 0번 셀부터 계속 자동 읽기
            └──────────┘  엔코더 누름              → 현재 셀 다시 출력, 간격 처음부터
```

- **끝 신호**: 처음/마지막 셀에서 더 이동하려 하면 모든 돌기를 잠깐 내렸다가 현재 셀을 다시 올린다. 화면 없이도 "더 이상 없음"을 알 수 있게 한다. 자동 읽기에서 속도를 더 바꿀 수 없을 때도 같은 신호를 쓴다.
- **띄어쓰기**: 빈 셀(돌기 모두 내림)로 출력한다.
- **길게 누르기**: 버튼2를 1초 이상 누르고 있으면 자동 읽기를 켜거나 끈다. 짧게 누르기는 손을 뗄 때 동작한다.
- **자동 읽기 속도**: 5단계 (셀당 3.0 / 2.0 / 1.5 / 1.0 / 0.7초), 처음은 2.0초. 마지막 셀이면 처음부터 시작한다. 속도 단계는 전원을 끌 때까지 기억한다.

## 3. "가나다" 예시 흐름 (약자 적용, 기본값)

| 단계 | 셀 번호 | 출력 | 의미 |
|---|---|---|---|
| 버튼1 | 0 | ⠫ (1-2-4-6) | 가 (약자) |
| 버튼2 | 1 | ⠉ (1-4) | 나 (약자) |
| 버튼2 | 2 | ⠊ (2-4) | 다 (약자) |
| 버튼2 | 2 | 끝 신호 | 마지막 셀 |
| 버튼4 | 0 | ⠫ | 처음부터 |

약자를 끄면(`--no-abbrev`) `⠈ ⠣ ⠉ ⠣ ⠊ ⠣` 6셀로 한 자모씩 읽는다.
